## Project name
বাজার দর / BazarDor

## Short description

বাজার দর / BazarDor is a simple and reliable platform to check the latest prices of essential products in Bangladesh. Compare today’s prices with yesterday’s, track price changes, and explore market-wise price information—all in one place.

## Technologies used

1. Next.js
2. React
3. TypeScript
4. Tailwind CSS
5. Better Auth
6. React Icons

## 5 key features of the project

5 Key Features of বাজার দর / BazarDor
1. Latest Product Prices — View current prices of essential products in Bangladesh.
2. Daily Price Comparison — See how much prices have increased or decreased compared to yesterday.
3. Market-Wise Prices — Explore product prices across different markets and locations.
4. Product Details — View product information, pricing summaries, and market-specific price ranges.
5. Responsive Design — Enjoy a user-friendly experience on desktops, tablets, and mobile devices.
